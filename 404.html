Peak Slab

What is it?

Peak Slab is an offline knowledge retrieval engine. (E.g. dictionaries, bibles, sheet music, media) The name comes from the Khmer words ពាក្យ ស្លាប់ which means word [that is] dead, a reference to the Ten Commandments which were written on Slabs of stone received on a mountain Peak.

Technical Details

Peak Slab is tiny (the core js, wasm, css, and html is under 128kb uncompressed) and very fast (runs multiple dictionaries in parallel even on old systems). Learn more on Github.
